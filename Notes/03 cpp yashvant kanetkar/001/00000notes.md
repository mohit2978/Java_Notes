`boolalpha` is a manipulator

In C++, `std::boolalpha` is a manipulator used with input/output streams to make boolean values (true/false) print as text instead of 1/0, and vice versa for reading.

```cpp
#include <iostream>
using namespace std;

int main() {
    bool flag;

    cout << "Enter true or false: ";
    cin >> boolalpha >> flag;

    cout << "You entered: " << boolalpha << flag << endl;
}

```
Input: false

Output: You entered: false

Without boolalpha, entering false would fail or be interpreted incorrectly.

When `std::noboolalpha` is active (which is the default behavior), the stream treats boolean input and output as:

true → 1

false → 0

So by default false value is treated as 0 and true value as 1 unlike `java`

🧠 What does alignment mean?
- Alignment is the requirement that variables of a certain type must be stored at memory addresses that are multiples of a specific number (alignment value).

- For example, if alignof(double) is 8, it means a double should be stored at an address divisible by 8.

```cpp
#include <iostream>
#include <type_traits>  // for std::alignof
using namespace std;

int main() {
    cout << "Alignment of char: " << alignof(char) << endl;
    cout << "Alignment of int: " << alignof(int) << endl;
    cout << "Alignment of double: " << alignof(double) << endl;
    cout << "Alignment of long double: " << alignof(long double) << endl;
}

```

Output :

```text

Alignment of char: 1
Alignment of int: 4
Alignment of double: 8
Alignment of long double: 16

```

`alignas` is a specifier introduced in C++11 that allows you to explicitly set the alignment requirement (in bytes) of a variable, struct, or class.

```cpp

struct a {
    char t;
    alignas(4) char p;
};

```
🧠 What it means:
- t is a normal char, 1-byte aligned.

- p is a char, but you’re explicitly telling the compiler:
“Align this char on a 4-byte boundary.”

So, even though p only needs 1 byte, it will start at a memory address divisible by 4, which will cause padding between t and p.

🔍 Memory Layout:
On a 64-bit system, here's likely what happens:

|Offset	|Member	|Size	|Note|
|-------|-------|-------|------|
0|	t	|1	|char
1–3|	padding	|3	|to align p to offset 4
4	|p	|1	|char, aligned to 4
5–7	|padding	|3	|to align struct size to 8

padding is just dummy bytes!!


```cpp

#include <iostream>
#include <type_traits>

struct a {
    char t;
    alignas(4) char p;
};

int main() {
    std::cout << "sizeof(a): " << sizeof(a) << '\n';
    std::cout << "alignof(a): " << alignof(a) << '\n';
    std::cout << "offset of t: " << offsetof(a, t) << '\n';
    std::cout << "offset of p: " << offsetof(a, p) << '\n';
}

```

Output:

```text

sizeof(a): 8
alignof(a): 4
offset of t: 0
offset of p: 4

```

The alignment of a struct is the maximum alignment required by any of its members.

so maximyum alignment we get above is 4 so structure alignmnet is 4!!

```cpp

alignas(4) struct a {
    char t; // 1 byte
    char p; // 1 byte
};

```

#### ❓ What does alignas(4) on the struct itself mean?
It means:

- The entire struct a must be aligned on a 4-byte boundary, regardless of what its members require.

- So, the struct's alignment becomes 4, even though both members (char) naturally only require 1-byte alignment.

🔍 Memory Layout:

 |Offset	|Member	|Size	|Note
 |----------|-------|-------|------|
0|	t	|1	
1	|p	|1	
2–3	|padding	|2	|To make sizeof(a) a multiple of 4

 ### Size & Alignment:
sizeof(a) = 4
(2 bytes for data + 2 bytes padding to meet 4-byte alignment requirement)

alignof(a) = 4
(because of alignas(4) on the struct)

```cpp
#include <iostream>
#include <type_traits>

alignas(4) struct a {
    char t;
    char p;
};

int main() {
    std::cout << "sizeof(a): " << sizeof(a) << '\n';
    std::cout << "alignof(a): " << alignof(a) << '\n';
    std::cout << "offset of t: " << offsetof(a, t) << '\n';
    std::cout << "offset of p: " << offsetof(a, p) << '\n';
}

```

Output:

```text 

sizeof(a): 4
alignof(a): 4
offset of t: 0
offset of p: 1

```
